# 水日常：安卓源码与功能预览

原生 Java Android 项目，支持 Android 8.0 及以上，无第三方运行依赖、无网络权限。数据使用 SharedPreferences 在本机保存；禁用系统备份。浏览器预览是独立交互演示，不是安卓模拟器，不会在后台发送系统通知。

## 体验

打开 `preview.html`：记录150/250/350 ml或自定义杯量、撤销最近记录、设置当天体重/运动/炎热状态及手动目标、配置提醒、查看最近七天。演示初始为空，无虚构饮水记录。

## 构建

1. 安装 Android Studio，配置 JDK 17、Android SDK 35。
2. 打开本目录，使用 Gradle 8.9 导入项目。当前交付没有 Gradle Wrapper 二进制；可安装 Gradle 8.9 后在项目根目录执行 `gradle wrapper --gradle-version 8.9`，再用 Android Studio 同步。首次同步需联网下载 Android Gradle Plugin 8.7.3。
3. 执行 `gradlew.bat assembleDebug`；生成的测试APK位于 `app/build/outputs/apk/debug/app-debug.apk`。
4. 安装后，在提醒页面开启提醒并保存；Android 13及以上允许通知权限。发布版本需要配置自己的签名，测试APK不用于商店发布。

## 已实现

- 中文今日进度与饮水日志；自定义杯量1–1000 ml、撤销最后一笔。
- 每日体重、运动分钟、炎热状态；运动/炎热数据午夜失效，体重沿用。
- 自动目标或手动目标。历史日志按本地日期保存；历史目标在记录或保存数据时快照。
- 开始/结束时间与30–180分钟间隔；不支持跨午夜作息。
- Android AlarmManager非精确通知；免打扰时段不发通知，完成目标后当天停止；重启及时间/时区改变后重新排程。
- Android 13通知权限请求，以及系统通知设置入口。

## 估算与限制

自动目标 = 体重kg×30 + 当日运动分钟×5 + 炎热时250 ml，取50的倍数并限制在1200–3500 ml。这是未经过临床验证的产品规则，并非按身体数据计算出的精确生理需求。可设置手动目标500–5000 ml，输入上限不是安全饮水上限，不要为了达标强行补水。

面向一般成年人的生活记录。儿童、孕哺期及有心肾疾病或限水医嘱者需按专业建议设置目标。茶、奶等饮品可以记录；食物含水量未计入。NHS饮水指南说明日常补水需求因活动及炎热等因素而异，并说明其他饮品也计入液体摄入：https://www.nhs.uk/live-well/eat-well/food-guidelines-and-food-labels/water-drinks-nutrition/ 。该来源不验证本项目的自动公式。

通知采用Android推荐的非精确闹钟，可能被系统省电策略延迟。强行停止应用后需重新打开；部分厂商设备需在系统设置中允许后台运行。拒绝通知权限时仍可记录饮水。

## 验证状态

已生成 `HydroDaily-1.0-debug.apk`，支持Android 8.0及以上。Java类已编译，Gradle打包完成，并执行Android Lint与APK签名验证。此电脑的Gradle Java编译任务在SDK文件路径检查阶段遇到AccessDeniedException，因此使用直接javac生成类，再由Gradle打包；javac退出码为0，但关闭SDK JAR时仍有路径权限警告。这是本机构建环境的限制，标准Android Studio构建流程无需该绕过步骤。

该APK使用测试签名，未进行真机安装与通知测试，不是商店发布版本。预览可用于审阅交互，不能证明原生通知行为。

安装后应验证：输入边界、记录与撤销、关闭再打开数据保留、跨日切换、通知允许/拒绝、作息外不提醒、完成目标停提醒、重启后恢复、锁屏与省电状态下通知延迟。
